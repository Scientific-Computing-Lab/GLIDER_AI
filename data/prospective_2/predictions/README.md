# Frozen Panel-II predictions

Method subfolders retain outputs on the same **96 Panel-II configurations**. The camera-ready GLIDER model is [`previous_candidate/`](previous_candidate/README.md), the original frozen checkpoint. An additional `candidate` archive remains for scientific provenance but is not the paper's Figure 3 result. MACE-POLAR-1-L is the response-unfitted polar baseline. Use [`configuration_registry.csv`](../configuration_registry.csv) and method manifests to align cases before scoring.
