# Panel-I QM references

`observable_registry.csv` maps the 48 frozen configuration IDs to compressed QM arrays. References were produced after model predictions were frozen. The measured quantity is the complex-minus-ghost-fragments electronic response at a shared nuclear geometry/basis, not a solvation energy. See the [panel overview](../README.md) and the [integrity verifier](../../../scripts/reproduce/verify_release.py).
