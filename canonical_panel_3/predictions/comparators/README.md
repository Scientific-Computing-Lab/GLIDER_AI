# Eligible Panel-III comparators

These outputs were frozen on the same 80 configurations as GLIDER before QM scoring. MACE-POLAR-1-L is the **polar baseline** in the paper's spatial-ESP comparison; the other models provide either a spatial field or a more limited observable according to their native outputs. `zero_response` and `static_thole` are controls. See each method's README and the [paper result map](../../../results/README.md) before interpreting an error column.
