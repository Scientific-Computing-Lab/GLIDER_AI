# Fixed GLIDER predictions for Panel III

These 80 per-configuration response predictions were produced with the same five-member checkpoint used for Panels I and II, before the Panel-III QM references existed. [`ALL_PREDICTIONS_FREEZE_MANIFEST.json`](../ALL_PREDICTIONS_FREEZE_MANIFEST.json) records that boundary. The paper's response-ESP aggregate is **0.427 NRMSE**; the per-solute comparison and uncertainty are in the [paper map](../../../results/README.md). Each archive contains response sites and reconstructed observables, not total complex energies.
