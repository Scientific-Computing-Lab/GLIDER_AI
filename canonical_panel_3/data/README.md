# Frozen Panel-III geometries

[`configurations.extxyz`](configurations.extxyz) and [`configuration_registry.csv`](configuration_registry.csv) fix 80 solute–three-water structures from 20 independently sourced solutes. [`GEOMETRY_MANIFEST.json`](GEOMETRY_MANIFEST.json) records their construction. The geometries were frozen before GLIDER/comparator prediction and later QM response calculation. See [selection](../selection/README.md) for the identity-only source and exclusion rules.
