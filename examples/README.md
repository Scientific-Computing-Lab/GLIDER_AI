# One published geometry, without a label

[`one_response_geometry.extxyz`](one_response_geometry.extxyz) is one Panel-I solute plus three waters, copied from the first frame of the archived prospective geometry file. It has an ASE-compatible `config_id`, `molecule_id`, `regime` and fragment IDs so the [geometry-to-response inference script](../scripts/benchmark/README.md) can run directly. It contains **no QM response label**. The matching frozen prediction and reference can be located through [`data/prospective_1/`](../data/prospective_1/README.md) after running or inspecting the archive.
