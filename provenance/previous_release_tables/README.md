# Underlying numeric source data

These are the data behind paper and appendix displays: geometry coordinates, individual or paired observations, bootstrap summaries, probe placements and the [`SourceData.xlsx`](SourceData.xlsx) workbook. They are numerical materials for reuse; no manuscript PDF, LaTeX file or camera-ready ZIP is stored here.

The filenames record their original plot-generation lineage. Use the [current figure/panel map](../../results/README.md) to find what appears in the SIMBIOCHEM camera-ready paper. `FIGURE_SOURCE_MAP.csv` and `FIGURE_ARTIFACT_MANIFEST.json` preserve earlier source/artifact names and hashes; the artifact manifest may name source figures that are deliberately outside this compact companion. [`probe_sweep/`](probe_sweep/README.md) carries accepted placements and observables for the fixed-charge and quantum-water distance checks.

**Measurement unit reminder:** response ESP is reported in hartree/e or mEh/e as labelled; energy and torque-like coupling errors are in kcal mol⁻¹; dipoles are in D. NRMSE is a normalized spatial response-potential error, not a total-energy error.
