# Label-blind identity selection

[`SELECTION_MANIFEST.json`](SELECTION_MANIFEST.json) locks the deterministic 20-solute selection. [`eligible_pool.csv`](eligible_pool.csv), [`selected_molecules.csv`](selected_molecules.csv) and [`exclusions_and_construction_failures.csv`](exclusions_and_construction_failures.csv) show the candidate space, final identities and logged exclusions. The input was an identity-only FreeSolv v0.52 extract; hydration free energies were not read. This panel tests a new identity source, not a hydration-energy endpoint.
