# Original Panel-III protocol scripts

The scripts here preserve the declared identity selection, geometry construction and freeze/evaluation sequence for the independent-source prospective panel. Read the [preregistration](../PREREGISTRATION.md), [selection manifest](../selection/SELECTION_MANIFEST.json) and [final report](../FINAL_REPORT.md) together: a script's ability to read a later file does not mean that file was available at the prediction freeze. The complete high-cost QM run is not needed to inspect the archived references and scores.
