# Panel-III model and rotation audits

These files document pre-QM checks of model execution, eligible comparator coverage and rotational behaviour on the canonical-source panel. [`GLIDER_ROTATION_AUDIT.json`](GLIDER_ROTATION_AUDIT.json) summarizes the equivariance test; [`rotation_predictions/`](rotation_predictions/README.md) stores its archived outputs. Some historical audit metadata includes the original computing environment's resolved checkpoint path; it is provenance, not a dependency for using this companion.
